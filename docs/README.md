# Paket Dokumen Base Prompt — Aplikasi Membership Mitra Frozen Food

Paket ini berisi dokumen markdown untuk dilempar ke AI builder / coding agent lain sebagai dasar pengembangan MVP aplikasi membership mitra jualan frozen food.

## Isi Paket
1. `ai_builder_master_prompt.md` — prompt utama untuk AI builder.
2. `blueprint.md` — blueprint produk dan arsitektur aplikasi.
3. `prd.md` — Product Requirements Document.
4. `brd.md` — Business Requirements Document.
5. `roadmap_mvp.md` — roadmap dari discovery sampai MVP release.
6. `user_stories_acceptance.md` — user story dan acceptance criteria.
7. `data_model.md` — rancangan database dan relasi data.
8. `api_spec.md` — rancangan endpoint API.
9. `psak_compliance.md` — pedoman desain transaksi agar siap PSAK.
10. `mvp_checklist.md` — checklist eksekusi MVP.

## Catatan
Dokumen ini adalah base text untuk pengembangan software. Untuk finalisasi kebijakan akuntansi dan laporan keuangan, tetap libatkan akuntan/CPA karena PSAK bersifat principle-based dan bergantung pada kontrak, skema pengiriman, retur, diskon, dan kebijakan usaha.
